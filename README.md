# Expense-Tracker
Expense Tracker

Technologies: Python, Streamlit, File Handling

Developed a web-based Expense Tracker application using Python and Streamlit to help users manage their expenses through an interactive interface.

Key Features

- Interactive web interface for recording and managing expenses.
- File handling to store and retrieve expense data from text files.
- Organized project structure for improved code readability and maintenance.

Project Type: Web Application
